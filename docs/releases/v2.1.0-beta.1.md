# AgentValue V2.1.0-beta.1

新增可选云空间，将日程、事项、执行回顾与资产同步到同一邮箱账号下的设备。原本机空间继续使用，不会因登录自动上传或清空原数据。

这是 **Windows x64 同步测试版**。V2.0 继续作为稳定版，本测试版不进入稳定版自动更新。安卓 APK 尚未提供，后续按“下载安装、登录即可用”交付。

## 本次新增

- 邮箱注册和登录，本机/云空间切换，不同账号的设备缓存分开。
- 事项、执行小计、目标、回顾、版本快照、Prompt、实验、图片和 Skill 文件同步。
- 离线先保存到设备，联网后上传；通常每 20 秒检查变化，恢复网络或回到应用时尝试同步。
- 不同记录修改自动合并；同一记录冲突显示两端内容，保存备份后由用户选择。
- 首次导入先自动备份，复制到空云空间，原 SQLite 与附件保留。
- 私有附件内容校验，先上传附件再上传引用记录；Skill 导出固定完整文件版本。
- 云空间完整备份恢复，恢复前下载当前备份。
- 独立手机网页和离线页面缓存，断网重启和登录过期时可查看已缓存数据。
- 电脑云提醒按账号与空间隔离。
- 桌面复制等待剪贴板写入完成后再提示成功，避免提前反馈或遗漏写入失败。
- 更新 README、使用说明、文档索引和路线图，明确平台与交付范围。

## 下载和升级

下载 `AgentValue-Setup-2.1.0-beta.1-windows-x64.exe`，运行安装向导。升级沿用安装位置和本机库，卸载保留数据目录。重要数据可先从原版导出完整备份。

安装后可直接使用本机空间。试用同步：右上角“本机空间” → 注册/登录邮箱账号 → 云空间 → “立即同步”。需要原数据时点击“备份并导入本机数据”。个人账号密码和数据库密码分开。

同一 Release 的 `SHA256SUMS.txt` 提供下载文件校验，另附 `latest.yml` 和 blockmap。此 Release 标记为 prerelease，稳定版更新只读取稳定 Release，不会自动安装本测试版。

## 验证范围

- 62 项自动测试通过，覆盖本机迁移与恢复、同步冲突、离线队列、删除传播、丢失响应后的重试、附件与完整 Skill 版本。
- 本地 PostgreSQL 验证初始化、账号数据隔离、版本检查和私有附件路径权限。
- 打包桌面原有功能回归与电脑/手机网页模拟同步场景通过；模拟场景不写真实云端。
- 实际 Supabase 初始化、邮箱登录和同步读取连接已检查。

真实 Windows 与安卓设备的双向写入、附件和断网恢复尚未完整验收，因此发布为测试版。最终发布检查以对应 GitHub Actions 结果为准。

## 当前边界

- 本次没有安卓 APK，也没有公共手机网页网址；网页源码用于测试及后续打包。
- 运行中的计时器只属于当前设备，完成的小计同步。
- 单附件上限 30 MB，首次导入总附件上限 200 MB，附件暂不自动清理。
- 手机网页关闭后无定时后台提醒，安卓后台能力将在 APK 阶段验证。
- 清除浏览器数据会删除未上传缓存，重要改动先确认同步或导出备份。
- 外部日历账号同步、在线生成、自动执行 Skill 不在本版范围；ICS 交换保留。
