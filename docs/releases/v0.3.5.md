# AgentValue 0.3.5

本次更新改进了文本 Prompt 的模板填写界面，让原文和待填写内容可以对照查看。

## 更新内容

- 填写模板时，左侧显示完整提示词，右侧集中填写变量。点击左侧的变量位置，可以直接定位到右侧对应的输入框。
- 每个变量使用柔和的半透明颜色标记，左侧位置和右侧输入框保持同色；同一变量在原文中出现多次时，只需填写一次。
- 输入时，左侧原文中的变量位置会立即显示填写内容。确认后仍通过“填写并复制”复制完整结果，收藏的原始提示词不会被改动。
- 精简界面文字，移除了顶部英文提示和变量序号；增加填写进度与“重置填写”按钮。
- 补充桌面程序的界面检查，覆盖左右对应、即时替换、复制结果及原始提示词保留。

## 安装与更新

下载下方的 `AgentValue-Setup-0.3.5-windows-x64.exe`，按安装向导选择安装位置。已安装用户可以在软件设置中检查更新，也可以运行新版安装包更新。个人数据默认保存在所选安装目录的 `data` 文件夹中，更新和卸载时保留；此前自行选择的数据目录仍可继续使用。

本次没有更改个人数据格式。安装包、更新信息文件和 SHA-256 校验文件均附在本次发布中。
