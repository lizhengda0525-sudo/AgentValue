# AgentValue V2.0

AgentValue 从资产收藏库扩展为本地日程与执行管理软件。事项、日程、目标、计时、小计、回顾和资产库均可实际保存、修改、备份与恢复。

## 新功能

- 名称一行录入事项；列表、看板、时间线及年/月/周日历；日期、时间、项目、优先级和截止日期可稍后填写。
- 年度与月度目标；按相同项目的已排期事项计算进度。
- 专注开始、暂停、继续与重启续计；实际执行小计支持补录、修改与删除，跨日记录分开统计。
- 每日回顾生成、编辑、保存快照及 Markdown 导出；周/月汇总支持修改并导出；计划与执行可导出 CSV。
- 重复事项支持每天、工作日、每周、每月；完成后创建下一次，历史记录保留。
- ICS 日历文件预览、导入、导出和重复导入去重；支持全天、跨日、UTC 与含 VTIMEZONE 的时区事件。重复事件按所选日期起一年展开为独立事项，遵循例外日期和改单次事件；无法解析的条目明确列出，不猜测未知时区。
- 桌面任务提醒需在事项详情开启。应用运行时按计划时间提醒；未定时间的当天事项默认 09:00。同一计划不会在重启后重复提醒；系统需允许通知。
- 关闭窗口后驻留托盘；右键托盘退出。Ctrl+Shift+Space 打开快速录入（快捷键被其他软件占用时可从托盘打开）。
- 事项关联 Prompt、图片提示词或 Skill，直接打开原资产；原有图片、评分、实验快照、模板、GitHub Skill 导入与更新全部保留。
- 图标 1 统一用于网页和桌面；使用本地 MiSans 字体及 Ant Design 交互组件；左侧资产库默认展开。

## 数据与升级

首次启动为空库，不放入虚构日程或资产。SQLite 保存助手记录和资产，旧版 Schema 1/2 自动迁移至 3。安装位置、数据目录与原有迁移方式沿用旧版；升级不会清空个人数据，卸载保留数据目录。

完整备份包括助手记录、Prompt、图片和 Skill。恢复需确认整库替换，先保存恢复前的备份；文件校验失败不会替换当前库。保存失败及多窗口冲突会明确提示，并提供草稿导出和重新载入。

浏览器使用本机服务，支持当前全部页面及 ICS 导入导出；Skill 导出 ZIP、备份导出 JSON。托盘、全局快捷键、系统通知、数据目录迁移和安装程序更新使用桌面版。

## 下载与验证

下载 `AgentValue-Setup-2.0.0-windows-x64.exe`，运行安装向导。安装版无需 Node.js、Codex 或 API Key；GitHub Skill 导入仍需 Git。

发布流程执行数据测试、界面检查、构建、打包后的真实窗口验收，以及安装/升级/卸载的数据保留测试，通过后才发布安装包。下载包的 SHA-256 见同一 Release 中的 `SHA256SUMS.txt`。

本版不包含外部日历账号连接、跨设备云同步、在线 AI 生成或自动运行 Skill。日历文件交换已实现；导入的外部事件修改后需重新导出文件，不会直接写回外部账号。
