## GitHub 调研与选择

对比 [Radix Primitives](https://github.com/radix-ui/primitives) 与 [shadcn/ui Select](https://ui.shadcn.com/docs/components/radix/select)。选择 Radix 的 Select 基础组件，安装 `@radix-ui/react-select` 2.3.7，单独封装和设置样式，避免为了几个下拉菜单引入整套新的页面样式。

依据 [Radix Select 官方文档](https://www.radix-ui.com/primitives/docs/components/select) 使用触发按钮、弹出层、选项和选中标记；菜单根据屏幕边缘调整位置，支持方向键、Enter 和 Escape。保留原表单字段名称，通过隐藏字段让效果评分正常进入表单保存流程。选择菜单打开时暂停外层弹窗的 Escape 和焦点循环，关闭菜单后恢复。
