# AgentValue 0.4.0 本地实现说明

完成日期：2026-10-06。版本仅在本地构建，尚未推送或发布到 GitHub。

## 可使用的功能

| 页面        | 实际行为                                                                    |
| ----------- | --------------------------------------------------------------------------- |
| 今天        | 名称一行录入、当天事项、计划与实际时间对照、专注计时、执行小计              |
| 事项        | 收件箱、日期安排、分类、优先级、项目、截止日期、状态、列表/看板/时间轴      |
| 日历与目标  | 年/月/周视图、月度目标增删改、同项目事项完成进度                            |
| 每日回顾    | 按真实计划与执行记录生成正文、修改草稿、保存快照、导出 Markdown             |
| 图片提示词  | 参考图与效果图上传、评分、排序、封面、大图、不可变 Prompt 快照及多次实验    |
| Prompt 管理 | 新增、编辑、全文搜索、标签、收藏、模板变量填写和复制                        |
| Skill 管理  | 本地文件夹与公开 GitHub 仓库导入、版本检查、更新、信息编辑、复制或 ZIP 导出 |
| 设置        | 查看数据位置、完整备份、校验和恢复；桌面端支持迁移目录与软件更新            |

左侧直接显示导航，资产库默认展开；按钮、下拉框、日期/时间、弹窗、抽屉、提示和图片预览统一使用 Ant Design。MiSans 字体在本机加载，字号规范见 `docs/typography.md`。已选图标 1 应用于导航品牌、网页图标、桌面窗口和安装包。

## 数据与启动

首次打开为空库，不自动添加演示任务或资产。桌面开发版与浏览器版默认共用仓库下 `data/agentvalue.db`；可用 `AGENTVALUE_DATA_DIR` 指定独立目录。安装版沿用原有安装目录和迁移规则。

助手与资产使用同一 SQLite 数据库，Schema 为 3。旧版 Schema 1/2 自动迁移并保留资产。助手保存是事务操作；多窗口写入冲突会显示错误并保留当前草稿，提供重试、导出草稿和重新载入。页面显示保存状态，不把保存失败显示成成功。

计时保存开始时间及暂停区间，关闭软件后重新打开仍会继续计算运行中的计时。结束工作后应暂停计时；小计记录实际秒数，跨日记录分开统计。

开发启动使用 `pnpm dev`。生产页面使用 `pnpm build` 后执行 `pnpm serve`，地址为 `http://127.0.0.1:5173/`。服务仅监听本机，写操作检查来源和会话；私有数据目录不加入 Git 或安装包。

## 备份与恢复

完整备份包含任务、日志、目标、回顾、计时状态、Prompt、图片及 Skill 文件。桌面端导出目录式备份；浏览器端下载 JSON 文件，可上传校验并恢复。浏览器端 Skill 导出为可解压的标准 ZIP。

恢复需确认替换全部记录；恢复前自动保留当前数据的完整副本。校验失败不替换现有数据，恢复中断可在下次启动回退。恢复后重新读取数据并重置页面状态，避免使用恢复前的缓存。

## 验收

- 42 项自动测试覆盖数据持久化、写入冲突、校验、跨日计时、旧库升级、备份回滚及资产管理。
- HTTP 接口实测覆盖图片文件、原始快照、评分、Skill 文件夹导入、标准 ZIP 解压、整库备份和恢复。
- 真实 Electron 窗口验收覆盖实际剪贴板、原生文件选择、图片管理、模板、Skill 导入及复制、重启持久化，以及助手的录入、重启续计、小计、回顾与目标。
- 桌面验收输出：`artifacts/smoke-results.json`；GitHub 导入验收输出：`artifacts/github-results.json`。
- Windows x64 安装包：`release/AgentValue-Setup-0.4.0-windows-x64.exe`。

## 范围

这版是可实际使用的本地软件。日程与提醒在应用内展示；没有接入外部日历、账号或跨设备云同步，也不会调用在线模型生成图片或自动运行 Skill。软件更新依赖已发布的安装版；本地 0.4.0 安装包不会自动发布到 GitHub。
