# AgentVault V1 · 优化后的实施方案

以用户提供的 AgentVault.txt 为需求素材，范围维持个人、本地、离线收藏管理。无账号、云同步、在线生成或 Skill 执行。

## 关键调整

1. SQLite 是文字与关系的唯一数据源；不同时维护 prompts 文件夹中的另一份正文，避免修改失步。图片与 Skill 文件仍存磁盘。导出时生成独立 JSON 与文件备份。
2. 普通与图片 Prompt 共用 prompts 表，以 kind 区分。每次 Generation 保存当时的正文快照、模型、参数、尺寸、比例、评分与备注；修改 Prompt 不会篡改历史实验。
3. 参考图直接关联 Prompt；效果图关联 Generation。封面优先使用最新效果图，只有参考图时使用参考图。没有图片时显示明确占位。
4. 原子数据库事务、外键约束、版本化 schema；图片采用随机内部标识，不依赖原文件路径。删除前确认；删除记录后暂保留媒体文件，备份包含完整库。
5. Skill 导入为独立副本，不改来源。拒绝符号链接、超大目录、路径逃逸；不运行仓库内脚本。重复来源不重复导入。复制到项目不覆盖同名目录。
6. GitHub 仅接收公开仓库根 URL，克隆后选择 Skill。保存仓库、相对路径、Commit；检查更新与更新分离。手动更新先暂存再交换副本，不做自动更新、合并或回滚。
7. UI：首页、Skills、文本 Prompt、图片 Prompt、设置。统一搜索、标签、收藏；图片使用画廊，详情承载实验记录。空库提供可选文本示例，不混入虚构资产。
8. Electron + React + TypeScript + Vite；使用 Electron 内置 node:sqlite，V1 不引入 ORM、组件生成器或额外 CSS 构建层。隔离渲染进程，只暴露明确 IPC 操作；媒体通过受限自定义协议访问。

## 实施与验收

- 基础：可启动窗口、数据目录、数据库初始化、设置备份。
- 文本：新增 → 标签/分类 → 搜索 → 编辑 → 收藏 → 复制 → 重启持久化。
- 图片：正文 + 多张参考/效果图 → 实验元数据 → Gallery → 大图/快照 → 复制；支持后续追加实验。
- Skill：本地或 GitHub 扫描选择 → 导入 → 搜索正文/标签 → 查看文件 → 复制到项目；检查/手动更新。
- 自动验证：事务回滚、历史快照、路径边界、拒绝覆盖、重启持久化、Git 更新以及真实 Electron 窗口流程。

## 边界

V1 使用本地全文子串搜索，适合个人库；不承诺大规模索引性能。私有仓库和 tree/分支 URL 后续再支持。备份导出为目录，恢复需退出应用后替换数据目录。暂不做自动媒体清理，避免删除共享或需要恢复的文件。
