# 桌面使用与数据管理

## 安装和第一次使用

从 [GitHub Releases](https://github.com/lizhengda0525-sudo/AgentValue/releases) 下载 Windows x64 安装包。V2.0 为稳定版；V2.1.0-beta.1 为同步测试版，需要手动下载安装。

安装向导允许选择位置。安装后从桌面或开始菜单启动，无需 Node.js、Codex 或 AI API Key。首次打开为空库，设置页可以按需添加明确标注的文本示例。

先在“今天”输入事项名称并回车保存，再按需设置时间或项目。实际执行时开始专注，结束后记录小计；每日回顾可以汇总当天计划和执行。Prompt 和 Skill 可从事项关联后直接打开。

## 安装目录、升级和卸载

建议安装到 `%LOCALAPPDATA%\Programs\AgentValue\app`，默认数据位于该目录下的 `data`。如果选择 `E:\AgentValue`，默认数据位于 `E:\AgentValue\data`。

后续更新沿用所选位置，不清空个人数据。可从软件设置或 Windows“已安装的应用”卸载，两种方式均保留本机 `data` 目录。设置中可迁移到空文件夹，迁移成功前保留原目录。

旧版 `%USERPROFILE%\.agentvault` 或旧安装位置旁的库按迁移规则复制，旧目录不会自动删除。原 Schema 1/2 可迁移到当前 Schema 3。

应用运行时检查 GitHub 稳定版更新，用户确认后下载并重启安装。稳定版不会自动下载同步测试版；测试版的后续测试版本也使用手动下载。旧版 0.3.2/0.3.3 的自选目录更新问题可通过手动安装 0.3.4 或更新版本修复。

## 本机完整备份与恢复

在本机空间设置中导出完整备份。备份包含 SQLite 库、图片、Skill 文件、JSON 清单和说明，文件使用 SHA-256 校验。

恢复时选择含 `manifest.json` 的目录，核对预览后确认替换。软件先保存当前完整备份到数据目录旁的 `<数据目录名>-recovery` 文件夹，再恢复所选库。可以选择恢复前备份撤销这次恢复；当前不支持部分导入或合并。

支持旧版 AgentVault Schema 1/2 备份。缺失文件、校验和不匹配、未来版本、符号链接和带 WAL/SHM 的不完整备份会被拒绝。校验上限为 100000 个文件、10 GB。

缩略图、Git 下载缓存和 Skill 更新的 `staging` 历史目录不包含在完整备份中。删除收藏后暂保留相关磁盘文件，不自动清理历史附件。

## 云空间

云空间首次使用需邮箱账号，和本机空间的数据分开。需要原本机数据时，使用“备份并导入本机数据”复制到空云空间；不会清空原库。

云空间完整备份为 JSON 文件，包含压缩记录和附件；恢复前先下载当前完整备份。浏览器版使用 JSON 备份和 ZIP 导出 Skill，桌面本机空间仍使用目录式备份。

单个云附件不超过 30 MB，首次导入总附件不超过 200 MB。已下载附件可离线查看，未下载图片显示待下载状态。清除浏览器缓存会删除未上传改动，应先确认同步或导出备份。

云配置、冲突与真实双端验证见 [多端同步说明](supabase-sync.md)。

## 提醒与快捷录入

桌面提醒需在事项详情中开启，并允许系统通知。应用运行时按计划提醒；关闭窗口后驻留托盘，右键可完全退出。未定时间的当天事项默认在 09:00 提醒。

Ctrl+Shift+Space 打开快速录入。快捷键被占用时，可从托盘打开。云空间提醒记录按账号和空间隔离，不影响本机空间。

## 日历与资产

ICS 导入先预览再确认，重复导入去重。全天、跨日和重复事件可展开；未知时区和无法解析的条目会明确列出。导入后编辑不会写回外部日历账号，需要重新导出文件。

Prompt 变量如 `{{语言}}`、`{{主题}}` 在复制前填写，同一变量只填写一次；`\{{变量名}}` 按字面复制。模板不执行脚本，原正文不会被填写值修改。

本机 Skill 支持本地文件夹与公开 GitHub 导入。本机 GitHub 导入需 Git，云空间使用公开接口；私有仓库不在当前范围。Skill 保留来源和版本，导入内容仅查看或复制，不自动执行。
