# AgentValue 当前路线图

更新于 2026-10-07。功能状态以当前版本说明为准，历史调研不等于当前承诺。

## 已交付：V2.0 本机管理

- 事项快速录入、列表、看板、时间线与日历。
- 年/月目标、专注计时、执行小计、每日回顾与汇总。
- 图片提示词、Prompt 变量模板、Skill 导入与更新。
- ICS、Markdown、CSV 导出，本机完整备份恢复。
- Windows 安装包、系统提醒、托盘与快捷录入。

## 当前发布：V2.1.0-beta.1 同步测试版

- 邮箱账号和独立云空间；本机库保留，可备份后复制导入。
- 按记录同步，离线修改持久保存；同记录冲突保留两端并提示选择。
- 图片和 Skill 文件私有存储、内容校验和、完整云备份恢复。
- 独立手机网页与离线页面，供双端测试和安卓复用。
- 自动测试及打包程序模拟双端场景已通过；真实账号登录与读取连接已检查。真实设备写入、附件和断网恢复仍待验收。

## 下一阶段：安卓 APK

用户使用流程：下载 APK → 安装 → 登录和电脑相同的账号 → 使用云空间。无需自行部署网站，电脑关机后手机仍可独立打开。

按以下顺序实现和验收：

1. 使用 Capacitor 接入安卓工程，将页面、字体、图标随安装包提供，连接同一个 Supabase 项目。
2. 适配安卓返回键、安全区域、键盘和文件选择；验证图片上传、Skill 文件导入与查看。
3. 接入可保存到手机的备份、CSV/ICS/Markdown 和 Skill ZIP 导出；隐藏桌面专用目录控制。
4. 固定应用签名和包名，生成 APK，验证安装、覆盖升级、数据保留及重新打开。
5. 用真实安卓手机和 Windows 安装版验收双向新增/修改/删除、附件、离线恢复、冲突和账号隔离。
6. 确认本地提醒、后台同步和系统通知的实际支持范围，再写进下载页；不提前承诺后台能力。

安卓尚未加入源码工程，也没有 APK；V2.1.0-beta.1 不包含安卓安装包。

## 正式同步版本的验收条件

- 原 Windows 本机数据、提醒、备份和更新回归通过。
- 两台真实设备新增、修改、删除后收敛，断网编辑和重启不丢失改动。
- 附件、离线缓存、Skill 完整版本导出和云备份恢复通过。
- 冲突内容可读，两端内容保留，恢复与选择前有备份。
- APK 安装与覆盖升级通过，发布签名可延续使用。

## 后续候选功能

外部日历账号同步、可选择内容的资产分享包、图片元数据提取、大库分页与搜索、可恢复回收站和附件空间管理。按反馈排期，不在本次测试版承诺中。

## 项目展示规划

- 仓库首页：一句功能说明、下载入口、平台状态表、实际截图、短上手步骤。
- Release：新增行为、升级和数据规则、实际验证范围；安装包附校验文件。
- 使用文档：桌面安装与备份、云同步和未来安卓下载分别说明。
- 文档索引：区分使用、开发、当前路线和历史研究，保留历史出处。
- 截图：只使用隔离测试库，标注样例，不展示私人日程、账号或本机路径。
- GitHub 简介：统一 AgentValue 名称，描述日程、回顾和资产管理，标出可选云同步。
