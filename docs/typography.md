# AgentValue 字体与排版规范

2026-10-05。工作台、资产库、导航、表单、弹窗、抽屉以及组件弹出层统一使用 MiSans，中英文、数字和 Prompt / Skill 文本保持同一字体风格。

## 字号与用途

| 用途                                 | 字号 | 字重                | 行高 |
| ------------------------------------ | ---- | ------------------- | ---- |
| 页面标题                             | 24px | 600                 | 1.4  |
| 弹窗标题、编辑标题、品牌             | 20px | 600                 | 1.5  |
| 分区标题、卡片标题                   | 16px | 600                 | 1.5  |
| Prompt 正文、回顾与长文本阅读        | 15px | 400                 | 1.6  |
| 正文、导航、按钮、表单标签与输入     | 14px | 400；操作强调 500   | 1.5  |
| 标签、日期、小计时间、说明与辅助信息 | 13px | 400；需要强调时 500 | 1.5  |
| 专注计时数字                         | 40px | 400                 | 1.4  |

字号按用途分级，同类信息使用同一级，不要求所有标题与正文同样大。正常可见文本不再使用 9–12px 的小字号；移动端沿用相同层级。仅用于隐藏文字的 `font-size: 0` 保留。组件行高若承担垂直对齐（例如菜单项高度），保留其布局行高。

## 使用规则

- `src/typography.css` 定义字号、字重、字体与行高变量；页面 CSS 使用变量，不在各处添加零散数值。
- `src/main.tsx` 的 Ant Design 字体配置与本规范一致，组件弹出层也使用 MiSans。
- 字重仅使用 400、500、600，分别对应 Regular、Medium、Semibold。正文不用细体，标题不使用浏览器合成粗体。
- 字距统一为正常字距，取消装饰性拉宽与压缩。时刻、时长和计时显示使用对齐数字。
- 代码及提示词保留换行与缩进，字形统一 MiSans。
- 普通按钮与输入的字体保持 14px；标签、日期等辅助信息为 13px。后续新增界面应直接复用这些等级。

## 字体资源

使用[小米官方 MiSans](https://hyperos.mi.com/font/download) 原始 WOFF2 文件，共三个字重，合计约 14.8 MB，内置于应用，不依赖操作系统安装或外部字体服务。字体未经修改或转换。资源来源与校验值见 `src/assets/fonts/README.md`。

设置页注明“界面字体：MiSans · 字体由小米提供”，并提供随应用打包的官方许可 PDF 入口。
